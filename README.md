# MDASHBOARD — مرجع متدولوژی توسعه داشبوردها

این مخزن چارچوب مرجع، قالب‌های استاندارد و ابزار شروع پروژه برای توسعه تکرارپذیر WEB APPهای داشبوردی است.

## شروع سریع
```bash
python tools/dashboard_onboard.py --repo OWNER/REPO
```

ابزار، REPO ورودی را می‌خواند، ساختار آن را با این مخزن مرجع مقایسه می‌کند، شکاف‌ها را نشان می‌دهد، اطلاعات ضروری را به‌صورت مرحله‌ای از مالک می‌پرسد، مشخصات ماشین‌خوان می‌سازد و با اجازه شما آن‌ها را به REPO مقصد Push می‌کند.

## احراز هویت
برای Push به GitHub، متغیر محیطی `GITHUB_TOKEN` یا `GH_TOKEN` با دسترسی Contents: write لازم است. REPO عمومی بدون Token قابل خواندن است اما برای نوشتن همچنان مجوز لازم است. Token را در کد یا REPO قرار ندهید.

## حفاظت
- فایل‌های موجود بدون تأیید صریح بازنویسی نمی‌شوند.
- ابزار، مشخصات تولید می‌کند؛ به‌طور خودکار کد اپلیکیشن یا backend تولید/اجرا نمی‌کند.
- هر داده مجهول، مجهول باقی می‌ماند.
- موفقیت Push، تست یا پیاده‌سازی فقط پس از دریافت نتیجه واقعی گزارش می‌شود.

## محتویات
- `docs/METHODOLOGY.md`: قواعد مرجع و مراحل تعریف.
- `docs/OPERATING_WORKFLOW.md`: گردش‌کار عملیاتی.
- `templates/`: قالب‌های مشخصات ماشین‌خوان.
- `tools/dashboard_onboard.py`: مقایسه REPO، مصاحبه مرحله‌ای، تولید فایل و Push.
